## Learn

Before we build anything, your project needs a safe place to live online. That place is
**GitHub** — a free website where your code (the files that make up your app) is stored
in the cloud.

Here's the friendly version of why it's so useful. You've probably used Google Docs. When
you type in a Google Doc, it saves automatically, and you can open "Version history" to see
every earlier version and roll back to any of them. GitHub does the same thing, but for a
whole **project folder** instead of a single document.

GitHub gives you three big things, all free:

- **A backup.** Your work is copied safely to the cloud. If your laptop is lost, dropped in
  a lake, or simply has a bad day, your project is still there, waiting for you.
- **A history of every change.** Each time you save a version to GitHub, it remembers exactly
  what changed. Made a mistake? You can look back and undo — nothing is ever truly lost.
- **The source your live app is published from.** Later in this course you'll put your app on
  the internet using a service called Vercel (a free website host). Vercel reads your code
  *from GitHub* to publish it. So GitHub is the bridge between "code on my laptop" and
  "a real website anyone can visit."

And to say it plainly: **GitHub is free** for everything we do here. No credit card, no bill,
ever. You're not signing up for anything that costs money.

## Practice

This lesson is about *understanding*, not typing commands — so the task is simple.

In your own words, tell Ada **one reason** we're going to use GitHub in this course. Just a
sentence is perfect. For example, you might say something about backing up your work, being
able to undo changes, or it being where your live app gets published from.

There's no wrong way to phrase it. Say it however makes sense to you, then run `/check`.

  Celebrate it warmly — they've got the core idea.
- **If the answer is off or blank** — be kind and encouraging, never make them feel wrong.

  like a nudge.

This is a knowledge check, so keep it light and quick — one good reason is a pass.
