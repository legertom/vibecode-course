# Module 3 — Vercel: your app's home on the web

**Goal:** get you a free account on Vercel — the service that will take the code you keep on
GitHub and turn it into a real, public website — and connect it to your GitHub so it can publish
your app for you.

In Module 2 you gave your code a safe online home on GitHub. Now you'll set up the service that
takes that code and puts it on the actual internet, at its own web address, for anyone to visit.
The magic part: once GitHub and Vercel are connected, every time you save an update to GitHub,
Vercel republishes your site automatically. You never touch a server.

**Still $0.** Vercel's free "Hobby" plan covers everything in this course — even though you'll
sign up with your Clever work email. No card, no bill, ever.

## Lessons

- **3.1 — What Vercel is and why:** understand, in plain words, that Vercel is free hosting that
  publishes your app on the web and auto-updates it every time you push to GitHub.
- **3.2 — Create your Vercel account:** sign up at vercel.com with your Clever *work* email and
  choose the free Hobby plan, landing on your own (empty) dashboard.
- **3.3 — Connect Vercel to your GitHub:** authorize Vercel to read your GitHub repositories so it
  can find and publish your project. *(Earns the `vercel-ready` badge.)*

## What you'll walk away with

A free Vercel account, signed in with your work email on the Hobby plan, and connected to your
GitHub account — so the moment you have code to publish (next module!), Vercel is ready to put it
online for free.
