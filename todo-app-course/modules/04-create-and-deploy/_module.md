# Module 4 — Create & Deploy the Skeleton

**The goal:** get a real, working app onto the internet with a live web address — *before* we
even build the to-do features. That first live URL is a huge, motivating win, and you'll have it
by the end of this module.

Here's the plan. First, Ada uses a tool called `create-next-app` to build a ready-to-run starter
app in seconds. You'll run it on your own computer to make sure it works. Then you'll put that
starter code on GitHub (its safe home) and connect it to Vercel, which publishes it to the world.

Everything here stays **$0**. Next.js and its starter tool are free and open-source. GitHub is
free. Vercel's Hobby plan is free. Nothing you do in this module can ever bill you.

## Lessons

- **4.1 Scaffold a Next.js app** — Ada builds a fresh starter app in a folder called
  `workspace/todo-app`.
- **4.2 Run it locally** — see the starter app running privately on your own computer.
- **4.3 Create the GitHub repo and push** — put your starter code safely on GitHub.
- **4.4 Import into Vercel → first LIVE URL** — publish it to the world and celebrate. *(Earns the
  **first-live-url** badge.)*

## What you'll walk away with

A working Next.js starter app that lives on GitHub **and** is live on the internet at a real
`something.vercel.app` address — one you can open on your phone and share with anyone. The
foundation is done; from here, we build the actual to-do app on top of it.
