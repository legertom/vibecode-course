## Module 5 — Build the To-Do App with Claude Code

This is the fun part. Your app is already live on the internet (from Module 4), but right
now it's just a starter page. In this module you'll turn it into a real, working to-do list —
by *describing what you want* to Claude Code and letting it write the code for you. You'll
also learn the quiet skill underneath all of this: how to ask Claude Code for a feature clearly.

Everything you build lives in one file — `workspace/todo-app/app/page.js` — and it all stays
**$0**. Your tasks are saved right inside your own browser (a free, built-in mini-storage called
localStorage), so there's no database, no server to rent, and nothing that could ever bill you.

### The lessons

- **5.1 — Plan it.** Write a tiny plan: the five features you'll build, and why saving in the
  browser keeps it free.
- **5.2 — Add + list.** Type a task, click Add, and watch it appear in a list.
- **5.3 — Complete + delete.** Check off finished tasks (with a line through them) and remove
  ones you don't need.
- **5.4 — Save with localStorage.** Make your tasks survive a page refresh — for free, no database.
- **5.5 — Style & polish.** A few styling touches to make it look clean and friendly. **Earns the
  `app-builder` badge.**

### What you'll walk away with

A genuinely working to-do app: add, see, complete, delete, and *remember* your tasks — built by
you directing Claude Code, running live on the web, at zero cost. By the end of this module the
app is done; Module 6 is about shipping your finished version and feeling the update loop.
